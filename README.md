# 🎵 Omnichord Web Synthesizer

A modern, web-based digital recreation of the classic analog OM-84 Omnichord instrument, built with vanilla JavaScript, Vite, and CSS. Play chords, strum strings, and jam out directly from your browser!

🌐 **Live Demo:** [https://omnichord-app.vercel.app/)

---

## ✨ Features

- **Custom Chord Matrix:** Build your own custom chord palette or play instantly using pre-set configurations.
- **Interactive Strumplate:** Real-time multi-string audio synthesis triggered by mouse drag or touch swipe.
- **Day/Night Theme Toggle:** Seamlessly switch between a clean light mode and a deep obsidian hardware-synth dark mode.
- **Fully Responsive:** Optimized for both desktop and mobile touch screens.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (with CSS Variables & Flexbox/Grid)
- **Logic:** Vanilla JavaScript (Web Audio API)
- **Build Tool:** Vite
- **Deployment:** Vercel
